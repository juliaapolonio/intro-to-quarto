Introdução ao Quarto

Minicurso — Simpósio Norte-Nordeste de Bioinformática

Bem-vindo ao minicurso Introdução ao Quarto!

Comece pela página Setup e materiais para preparar seu computador antes do início do curso.

Descrição

Relatórios de bioinformática costumam nascer partidos: o pipeline roda no cluster, as figuras saem em uma pasta, as tabelas em outra, e o texto é escrito em um editor que não faz ideia de onde aqueles números vieram. Quando o dado muda — e ele sempre muda — todo o trabalho manual de montagem precisa ser refeito.

Neste minicurso de 5 horas você vai aprender a usar o Quarto para escrever documentos em que texto, código e resultados vivem no mesmo arquivo. Vamos partir da notação Markdown e chegar a um relatório completo de expressão diferencial que se atualiza sozinho quando o dado de entrada muda.

O curso é prático e tranquilo: cada bloco termina em um exercício, e todas as soluções estão comentadas no material.

Público-alvo

Este curso é para você se:

  • trabalha com dados e precisa comunicar resultados (relatórios, artigos, apresentações, sites);
  • já escreveu algum código em R ou Python, ainda que pouco;
  • quer parar de copiar e colar figuras e números de um lugar para outro.

Não é pré-requisito saber R avançado, LaTeX, HTML ou CSS. Todo o código executado no curso usa R base.

  • Cinco exercícios resolvidos, do “olá mundo” ao relatório completo
  • Um documento que gera HTML e PDF a partir do mesmo fonte

Ferramentas

O curso usa o Quarto com o motor knitr (R). O ambiente vem pronto em um arquivo environment.yml do conda, e a IDE sugerida é o Positron — mas tudo funciona igualmente bem no RStudio, no VS Code ou em qualquer editor de texto com um terminal ao lado.

As instruções de instalação estão na página Setup e materiais.
