Setup e materiais

ImportanteFaça isso antes do curso

A instalação leva alguns minutos e depende de internet. Se você deixar para o dia, vai perder o primeiro bloco esperando o conda resolver dependências.

Instalação local

1. Clone o repositório

git clone https://github.com/juliaapolonio/intro-to-quarto.git
cd intro-to-quarto

2. Crie o ambiente conda a partir da receita

conda env create -f environment.yml

Se você usa mamba ou micromamba, troque conda por eles — a resolução é bem mais rápida.

3. Ative o ambiente

conda activate quarto-env

4. Abra o Positron

positron .

Se preferir, abra a pasta no RStudio ou no VS Code — o material funciona em qualquer um deles.

Verificando a instalação

Com o ambiente ativado, rode:

quarto check

A saída deve mostrar [✓] para o Quarto, o Pandoc e o motor knitr. Para testar de ponta a ponta, renderize o material do curso:

quarto render material/minicurso-quarto.qmd

Se o HTML abrir com figuras e tabelas, está tudo pronto.

AvisoDeu erro? Comece por aqui
Sintoma Solução
quarto: command not found O ambiente não está ativo: conda activate quarto-env
conda env create trava resolvendo Use mamba env create -f environment.yml
Erro de pacote LaTeX ao gerar PDF quarto install tinytex
there is no package called '...' conda env update -f environment.yml --prune

A lista completa de problemas comuns está no Anexo C do material.

Sem instalar nada

Se a instalação falhar no dia, você ainda consegue acompanhar:

  • Todo o material está publicado neste site — veja Material do curso.
  • Para escrever e renderizar .qmd no navegador, o Posit Cloud oferece um plano gratuito com RStudio e Quarto já instalados.
  • Você também pode acompanhar em dupla com quem tiver o ambiente funcionando — o curso é tranquilo o suficiente para isso.
